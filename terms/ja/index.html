📱 Appleライセンス契約
本サービスはAppleの標準エンドユーザーライセンス契約（EULA）に従います。

第1条（目的）

本規約は、Fitup（以下「当社」）が提供するフィットネスセンター管理サービス（以下「本サービス」）の利用に関し、当社と利用者との間の権利、義務、責任事項を定めることを目的とします。

第2条（定義）

1.「本サービス」とは、当社が提供する会員管理、クラス予約、出席管理、クーポン管理、コミュニティ機能等のすべてのサービスを意味します。

2.「利用者」とは、本規約に従って本サービスを利用する会員、インストラクター、店長を意味します。

3.「店舗」とは、本サービスを通じて管理されるフィットネスセンターを意味します。

第3条（サービスの提供）

当社は以下のサービスを提供します：

  • フィットネスセンター会員管理
  • クラス予約・出席管理
  • クーポン発行・管理
  • コミュニティ機能
  • プッシュ通知サービス

第4条（アプリ内課金および自動更新サブスクリプション）

⚠️ 自動更新サブスクリプションに関する重要なお知らせ

1. 本サービスの一部機能は有料で提供される場合があり、Apple App StoreまたはGoogle Playストアのアプリ内課金を通じて購入できます。

支払いと請求

2. 購入確定時にiTunes/Apple IDアカウントに代金が請求されます。

自動更新サブスクリプション

3. 自動更新サブスクリプションについて：

  • 現在の期間終了の24時間前までに自動更新をオフにしない限り、サブスクリプションは自動的に更新されます。
  • 現在の期間終了前24時間以内に、同じ金額でアカウントに更新料金が請求されます。
  • 期間中にキャンセルしても、その期間終了までサービスを利用できます。
  • 無料トライアル期間の未使用部分は、サブスクリプション購入時に失効します。

サブスクリプションの管理とキャンセル

4. 購入後、アカウント設定でサブスクリプションを管理し、自動更新をオフにすることができます。

  • iOS: 設定 → [ユーザー名] → サブスクリプション → Fitupを選択 → サブスクリプションをキャンセル
  • Android: Google Playストア → メニュー → 定期購入 → Fitupを選択 → 定期購入を解約

返金

5. 返金はAppleおよびGoogleの返金ポリシーに従います。返金リクエストは各ストアを通じて直接行う必要があります。
